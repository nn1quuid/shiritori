# Webしりとり
オンライン対戦形式、またはCPU対戦形式でしりとりが出来るウェブアプリです。

## 機能
- ユーザーネームだけで登録
- 2700単語以上を収録したCPU対戦
- 最大10人まで同時参加できるオンライン対戦ルーム

## 技術
- Node.js
- Express
- EJS
- Socket.io

## テストプレイ
[Renderにて公開中](https://shiritori-tcor.onrender.com/)

### ゲームルール
- 小さい文字（ゃ, っ等）は「や」として見る
- 伸ばし棒で終わる場合、その前の文字の母音から続ける（例: 「かれー」→「えんぴつ」等）
- カタカナで入力した場合もひらがなに変換される
- 重複不可
- 1文字～25文字
- オンライン対戦時、5分ほど放置した場合はルームからキックされる

## 起動方法
### インストール
`npm install`

### 起動
`node server.js`

環境変数不要
